# Brandonchinn178 Tap

## How do I install these formulae?

`brew install brandonchinn178/tap/<formula>`

Or `brew tap brandonchinn178/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "brandonchinn178/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
